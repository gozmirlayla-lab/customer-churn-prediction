# Données externes

Les données sont téléchargées à l'exécution dans `raw/` et exclues de Git.
`source.json` conserve URL et SHA-256 du fichier réellement utilisé.
Consulter les liens et conditions des sources dans le README principal.
Ne pas déposer de CV, coordonnées personnelles, secrets ou poids RoBERTa dans le dépôt.
